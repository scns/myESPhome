GOOD TO KNOW

A few things
before you start.

Still stuck? Let's figure it out.

Which ESP boards can I use?

The luxmeter and Vindriktning projects use a WEMOS D1 Mini with ESP8266. The Bluetooth proxy is built specifically for the ESP32-C3 DevKitM-1 with 4 MB flash. Check the required board before installing; an arbitrary ESP32 variant is not a substitute.

Does this work without Home Assistant?

These projects are designed for Home Assistant and its ESPHome integration. Initial USB installation works in your browser, but Home Assistant is the intended place to use your sensors and build automations.

Why isn't the install button available?

Use desktop Chrome or Edge over HTTPS, with a USB data cable. If firmware is marked unavailable, its release manifest could not be loaded. A source-only local preview has no firmware; a successful website publication includes the matching binaries.

How do I update a device after installation?

Complete the personal secure setup first, then use your own ESPHome configuration for encrypted OTA updates. ESP8266 public firmware does not use HTTP updates. Public firmware is for first setup and should not replace your personal configuration.

Can I install the projects in development?

Concept projects have no device implementation and are not installable. The experimental garage door project needs a personal configuration and hardware commissioning, so it is deliberately excluded from the web installer.
